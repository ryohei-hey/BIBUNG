# 科学的意味を保つ

文章が流暢でも、原文の主張を変えていれば改稿として失敗である。通常の推敲は原文との対応確認であり、原文の科学的正しさを独立に保証する作業ではない。

## 保持するもの

| 対象 | 点検する関係 | 禁じる変更の例 |
|---|---|---|
| 数値 | 値と対象・単位・分母・時点の結び付き | 28日死亡率を院内死亡率にする |
| 比較 | 誰を何と比較した結果か | 対照群の値を介入群へ移す |
| 統計 | 指標、方向、調整の有無、不確実性、有意性の言い方 | ハザード比をリスク比と呼ぶ。P=0.06を「低下傾向」にする |
| 主体 | 誰が行い、誰が判断・報告したか | 患者の自己申告を医師の判定にする。主体が異なる二文を一文にまとめて同じ主体にする |
| 否定 | 否定がかかる範囲 | 「全例で改善したわけではない」を「全例で改善しなかった」にする |
| 条件 | 対象・時点・例外・適用範囲 | 「評価可能な患者では」を落とす |
| 研究の位置付け | 観察、推定、解釈、仮説、探索、事前規定 | 事後解析を検証的解析と呼ぶ |
| 比重 | 主要評価項目と副次評価項目、事前規定と探索の扱いの重さ | 有意だった副次評価項目を、主要評価項目の非有意な結果より前に置く。主要評価項目の結果を「〜ものの」などの従属節に下げる |
| 評価の向き | 「わずか」「〜にとどまった」「依然として」「〜にもかかわらず」が示す著者の評価 | 「増加は1日320歩にとどまった」を「1日320歩増加した」にする。原文にない「顕著に」「わずか」を足す |
| 推奨の強さと確実性 | 推奨の方向・強さと、エビデンスの確実性を表す語の組み合わせ | 「提案する」（弱い推奨）を「推奨する」「望ましい」にする。確実性が低い知見の「可能性がある」を「おそらく」や断定にする |
| 実施状況 | 予定、実施済み、申請中、承認済み | 取得予定のデータを取得済みとする |
| 引用・図表参照 | 出典・図表・補足資料が支える具体的主張と、引用キー・図表番号 | 段落移動や文の統合により、別の主張や数値へ引用・図表参照を付ける |

数値の表記変更、丸め、単位換算、指標の換算は通常の文体編集では行わない。原文の数値から差や割合を新たに計算して書かない（10.0%と15.0%を「5ポイント低い」にしない）。語順を変える場合も、数値が何を表すかを保持する。コード・数式・引用キーが一致するだけでは科学的意味の保持を保証できない。

## 留保の扱い

独自作成した架空例：

- 「この結果は、関連がある可能性を示していると考えられる」のように留保が重なる文は、一つに減らしてよい。残す留保は原文の語から、原文の主張の段階（観察か、著者の推論か）を表すものを文脈で選び、全て外して断定にしない。例：「この結果は、関連がある可能性を示している」。「と考えられる」を一律に削らない。
- 「探索的解析では関連が示唆されたが、推定値の不確実性は大きい」は残す。「関連があった」だけに縮めない。
- 「有意差は認められなかった」は「差はなかった」「同等だった」に変えない。
- 「関連が認められた」は「改善させた」「予防できる」に変えない。「可能性がある」を付けるだけでも、原文にない因果的主張の追加になり得る。
- 原文が著者の推論・解釈を断定で書き、その根拠が本文にない場合は、「と考えられる」などの留保を補い、補ったことを修正理由に示す。例：「推奨が分かれた理由は、作成工程にある」→「作成工程にあると考えられる」。「手順は透明性を担保する」のように、条件がそろえば実現するとは限らないことを断定した文も同じに扱う。本文に根拠が示されている事実、定義、観察された結果、専門用語の定義には留保を足さない。全ての文末に留保を付けない。

## 推奨と確実性の言い方（GRADE）

診療ガイドライン、システマティックレビュー、その解説では、推奨の強さとエビデンスの確実性を表す語が、GRADEの判定に対応している。これらの語は文体の留保ではなく判定の記述なので、留保の整理や言い換えの対象にしない。

- 推奨の強さ：強い推奨は「〜することを推奨する」、弱い（条件付き）推奨は「〜することを提案する」で書き分ける（英語の we recommend／we suggest）。方向（行う／行わない）と強さを原文のまま保ち、「望ましい」「考慮する」「強く推奨する」などに置き換えない。強さの異なる推奨を一文にまとめない。
- 確実性：高・中・低・非常に低の判定には、効果の記述の言い方が対応する（英語の informative statements では、高「減少させる」、中「おそらく減少させる」、低「減少させる可能性がある」、非常に低「減少させるかどうかは非常に不確実である」）。効果の大きさを表す「わずかに」「ほとんど差がない」も判定の一部である。留保が重なった文を整理するときも、確実性に対応する語は残し、別の段階の語に置き換えない。
- 用語：「エビデンスの確実性」「推奨の強さ」「弱い推奨」などの用語と、本文中の判定の表記（「確実性：低」など）は原文の形を保つ。

独自作成した架空例：

- 前：輸液反応性に基づく輸液管理により、死亡率がわずかに低下する可能性があると考えられるかもしれない（エビデンスの確実性：低）。
- 後：輸液反応性に基づく輸液管理により、死亡率はわずかに低下する可能性がある（エビデンスの確実性：低）。
- 残す例：「おそらく」が「確実性：低」と並ぶなど、語と判定が対応していない場合は、どちらかに合わせて直さず要確認に挙げる。

ガイドラインの用語体系が原文に明示されている場合（Mindsの推奨度の表記など）は、その体系の語を保つ。

## 原文に問題がある場合

実質的な主張の矛盾や根拠不足は、文体修正で隠さない。明白に見える数値誤りも値を選び直さず、該当箇所を挙げる。

例：本文に「解析対象は80人」と「男性50人、女性40人」が併記されている場合、いずれかを推測で修正しない。改稿後に「要確認：解析対象数80人と男女別人数の合計90人が一致していません」と記す。

「初めて」「最大規模」「有効性を証明」など、事実や証拠の強さを含む主張は、装飾と見なして黙って削らない。根拠が入力から判断できない場合は確認事項とする。単に「画期的な研究」と自賛しているだけなら、原文にある具体的な目的を残して形容を取り除く。

曖昧さを原文内の別の記述で解消できる場合は修正してよい。その根拠を修正理由に示す。解消できない場合は、本文で一方に確定させず、読み方の候補を示して要確認に挙げる。語や句が二通りに読め、どちらかで主張の範囲が変わる場合も同じに扱う。

例：「重症例では中止基準を満たした」とあり、「重症例」が入院時に重症だった患者か、経過中に重症化した患者かを本文から決められない場合、読みやすさのために一方へ書き換えない。改稿後に「要確認：「重症例」は(a)入院時に重症だった患者、(b)経過中に重症化した患者のどちらを指しますか。回答に合わせて該当箇所を直します」と記す。

実施状況は一文ずつでなく、文同士でも照合する。「解析対象は80人であった」と「承認後にデータ取得を開始する予定」が併記されている場合、予定人数・予備解析・別データのどれを指すかは推測せず確認する。人数や新規性の問題を見つけても、実施状況の照合を省かない。和文と英文抄録で数値や結論が食い違う場合も、どちらかに合わせて直さず要確認に挙げる。

## 構造を変えた後の点検

段落の移動・統合後、主張ごとに原文の対応箇所を確認する。結果を述べる段落では、主要評価項目の結果を先に、独立した文で述べる原文の順序を保つ。副次評価項目や探索的解析の結果を前に出したり主文にしたりする並べ替えは、結果の印象を変えるため行わない。原文がすでに副次評価項目を先に置いている場合は、並べ替えずに修正理由で指摘する。重複として削った文に、別の対象・条件・留保がないか確認する。文を統合するときは、原文にある関係（並列・対比・時間順）を超える関係を作らない。「〜により」「〜ため」「〜ことで」は因果・手段を表すため、原文が関連や群間の差しか述べていない文をこれらで結ばない。例：「介入群では再入院が少なかった。調整リスク比は0.70であった」を「介入により再入院が減少した（調整リスク比0.70）」にしない。一般向けの説明を加える場合も、新しい事実や医学的助言に踏み込まず、入力にある概念の説明にとどめる。

直接引用、文献タイトル、固有名詞は言い換えない。引用内部に誤りが疑われても、編集対象本文と区別して指摘する。
